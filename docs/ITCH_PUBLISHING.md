# Publishing Water Sort on itch.io (play in browser)

Files are ready in this repo / your PC:

| What | Where |
|---|---|
| Upload zip (web build, `index.html` at the zip root) | `build/itch/WaterSort-web.zip` (11.5 MB; not committed, rebuild with the snippet below) |
| Cover image 630x500 | `assets/store/cover_630x500.png` |
| Screenshots (720x1280 portrait) | `assets/store/shot_*.png` |

## 1. Create the project
1. Log in at itch.io, then **Dashboard > Create new project**.
2. **Title:** Water Sort. **Kind of project:** HTML.
3. **Uploads:** upload `WaterSort-web.zip`, then tick **This file will be played in the browser**.
4. **Embed options** (shown after ticking the box):
   - Viewport dimensions: **540 x 960** (the game adapts to any shape, this just sets the default frame).
   - **Mobile friendly:** on, orientation **Portrait**.
   - **Fullscreen button:** on.
   - **Automatically start on page load:** **off**. The player's click on "Run game" is also the tap browsers
     require before they allow sound, so music and effects start reliably.
5. Upload `cover_630x500.png` as the cover image and the `shot_*.png` files as screenshots.
6. Pricing: **No payments** (or whatever you prefer). Visibility: start with **Draft**, open the page
   to test the embedded game, then switch to **Public**.

## 2. Page text (copy / paste)
**Short description:** A relaxing 100-level water sort puzzle with glowing glass tubes.

**Genre:** Puzzle. **Tags:** puzzle, casual, relaxing, singleplayer, mobile, touch-friendly, colorful, godot.

**Description:** itch's editor is a rich-text editor, so Markdown symbols (`>`, `-`, `**`) are NOT converted:
paste the plain text below, then format it with the toolbar (select text, click **B**, or the bullet-list
button, or a heading style). Keep each paragraph on a single line, or it becomes several paragraphs.

```
Sort the colours until every tube holds just one. Pour the top colour of a tube onto an empty tube, or onto a tube whose top is the same colour, and keep going until the puzzle is solved.

Features
100 levels in three chapters: Classic, Squeeze (only one spare tube) and Tall Tubes
Hint, Undo, Restart and a one-time extra tube per level
Colour-blind symbols you can switch on in Settings
Short tutorial for new players
Soft ambient music and water-themed sound effects (both can be switched off)
Works on phones, tablets and desktop; your progress is saved in your browser

How to play
Tap a tube to pick it up, then tap another tube to pour.

Credits
Made with Godot 4. All sounds and music were generated by script. Open source (MIT): https://github.com/vp125/water-sort
```

Formatting to apply after pasting: make **Features**, **How to play** and **Credits** headings (or bold),
select the six feature lines and click the bullet-list button.

## 3. Updating later
Rebuild and re-upload the zip (the page keeps its URL):

```
godot --headless --path . --export-release "Web" build/web/index.html
python -c "import zipfile,os;z=zipfile.ZipFile('build/itch/WaterSort-web.zip','w',zipfile.ZIP_DEFLATED);[z.write(os.path.join(r,n),os.path.relpath(os.path.join(r,n),'build/web')) for r,_,ns in os.walk('build/web') for n in ns if not n.endswith('.import')]"
```

Optional: itch's command-line uploader **butler** can push builds directly (`butler login`, then
`butler push build/web YOUR_ITCH_NAME/water-sort:html5`).

## Things to check on the live page
- Click **Run game**: music should fade in and tapping a tube should play a sound.
- Progress between visits: it is saved in the browser. Some browsers (notably Safari) limit storage for
  games embedded in another site's page, so if progress is not remembered there, that is the cause.
- Notch / safe-area spacing only applies to the native iOS app, not to the browser version.
